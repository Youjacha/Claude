# 변별 문항 출제 참고서 (4점 문항용)

2022 개정(대수·미적분Ⅰ·확률과 통계 공통) 모의고사의 4점 문항을 설계하는 사람을 위한 종합 문서이다. 네 시험의 심층 분석에서 **검증된 사실만** 모아 패턴, 슬롯 기준, 체크리스트로 정리했다.

| 기호 | 시험 | 상세 문서 | 검증 스크립트 |
|---|---|---|---|
| **E28** | 2028 수능 예시문항 (2028 체제 기준) | [2028-example.md](2028-example.md) | `scripts/verify_2028.py` |

## 0. 빠른 사용법

1. 맡은 **슬롯**(번호)의 목표를 §2에서 확인한다(난이도, 관문 수, 단계 수, 추천 패턴).
2. 추천 **패턴**(§1의 P번호)의 레시피를 따라 출발점 → 조건 → 수치 순서로 설계한다. 대표 기출의 '재사용 템플릿' 절을 연다.
3. 과목별 주의점을 §3에서 확인한다. 특히 확통의 원순열 제외와 모비율 추정 활용 여부.
4. §4 체크리스트를 통과시키고 검증 스크립트를 첨부한다. §5 안티패턴에 걸리지 않는지 본다.

### P1. 극한·연속·미분가능 → 근의 중복도
- **정의**: 분모가 0이 되는 점, 절댓값의 꺾인 점, 구간 경계에서 극한·연속·미분가능 조건을 걸어 **다항식 인수(근과 중복도)**를 강제한다.
- **작동 단계**: 첫 단계(번역)에서 가른다. 번역하지 못하면 시작조차 못 한다(E28-28 "존재 → 연속 → 중근").
- **대표 기출**:
  - E28-18: $x^3$ 분모 → 원점 3중 이상, 답 68.
  - E28-28: $|g(x)-g(k)|/(|x|-k)$ 연속 → $\pm k$가 같은 높이의 극점, 답 9.
  - S27-15: 집합 경계의 "≥" → 분모 중근과 분자 $(2x+1)$이 맞물림, 답 10.
  - S27-21: $g$와 $|k|$의 꺾인 점 상쇄, 답 12.
  - C26-21: 분모 $x(x-2)$ → $f(0)=f(2)=0$, 답 65.
- **레시피**:
  1. 인수분해된 함수(예: $c\,x(x-p)(x-\beta)$)에서 출발한다.
  2. 분모·절댓값 위치를 근에 맞춰 근을 하나씩 고정한다.
  3. 남은 자유도(계수 $c$, 근 $\beta$)를 값 조건으로 정한다.
  4. 마무리 연산으로 정수화한다($a+20k^2$, $g(-5)$).
- **적합 과목·번호대**: 미적분Ⅰ 18(준킬러), 28(킬러). 2028 체제에서는 단답 28번 자리.
- **흔한 실패**: 조건 하나가 근 두 개를 동시에 고정해 다른 조건이 중복되는 경우. 반대로 고정이 부족하면 해가 1차원 족으로 남는다(J27-21 "만"을 빼면 해가 늘어남).

### P2. 집합·범위 조건으로 함수 역추적
- **정의**: "조건을 만족하는 $t$의 집합은 ○", "음수가 되는 $m$의 집합은 {…}"처럼 결과를 집합으로 주고 함수를 거꾸로 결정하게 한다.
- **작동 단계**: 중간 단계. 집합의 **크기·경계**로 매개변수의 구간을 정하고, **원소 값**으로 계수를 정하는 두 단계로 작동한다.
- **대표 기출**:
  - J27-15: $p$의 범위 $(0,3)$ → 0은 중근, 3은 단순근, 답 27.
  - S27-15: $\{t\mid t\ge\frac32\}$ → $k=-\frac9{16}$, 답 10.
  - C26-21: 집합 $\{g(-1),-\frac72g(1)\}$ → $\beta=\frac{11}3$, $c=\frac3{14}$, 답 65.
  - E28-30: $x$좌표 집합 $\{0,a,b,c\}$, 답 90.
- **레시피**:
  1. 목표 함수의 근 구조를 정한다.
  2. 그 구조가 만드는 집합의 **경계**를 계산해 깔끔한 값(정수·반정수)이 되게 수치를 맞춘다.
  3. 경계를 닫힌/열린 것으로 지정해 추가 정보를 싣는다(S27-15의 "≥"가 위치를 고정함).
  4. 원소를 함숫값으로 주면 역추적이 한 단계 더 깊어진다(C26-21).
- **적합 과목·번호대**: 미적분Ⅰ 18·20·28. 원소를 함숫값으로 주는 형태는 킬러(28).
- **흔한 실패**: 집합 원소가 2개일 때 대입 순서 두 가지가 모두 해가 되는 경우 → 해 다수. C26-21은 비율이 1보다 작아지는 쪽이 자동으로 제거되도록 계수를 골랐다. 반드시 전수 확인할 것.

### P3. 부호 변화·넓이 장부(적분의 불변량)
- **정의**: $\int|f|$와 $\int f$의 관계, 정적분으로 정의된 함수의 극값을 **부호 변화와 넓이 조각**으로 처리하게 한다. 함수를 하나로 정하지 않고도 답(불변량)이 정해지게 설계할 수 있다.
- **작동 단계**: 관점 전환 한 번. 함수식을 세우려는 학생은 끝나지 않는다(E28-20: 미지수 4개, 조건 3개).
- **대표 기출**:
  - E28-20: $S_1=S_2=4$, $S_3=16$ → 답 12. 함수는 유일하지 않다.
  - J27-15: $\int|F|\ne|\int F|$ ⇔ 부호 변화.
  - C26-15: 극값 = $h'$의 부호 변화, 0에 접하는 점은 극값이 아님 → $k=4$, 답 $\frac{15}2$.
- **레시피**:
  1. 넓이 조각 $S_i$를 미지수로 둔다.
  2. 극값·적분 조건을 $S_i$의 일차식으로 쓴다.
  3. 묻는 값을 $S_i$의 조합(불변량)으로 고른다.
  4. 함수 존재는 수치로 따로 확인한다(E28-20에서 $C\approx0.7294$ 등 존재 예시를 제시).
- **적합 과목·번호대**: 미적분Ⅰ 20(5지 킬러)과 15·17(4점 보통~준킬러).
- **흔한 실패**: 존재 확인 누락(조건을 만족하는 함수가 실제로 없음). 묻는 값이 불변량이 아니어서 답이 여러 개 나오는 경우.

### P4. 합성 분해
- **정의**: $t$에 대한 함수 $g(t)$를 "$f(\alpha)=k$의 최대 실근 $G(k)$"와 $k=h(t)$의 합성으로 다시 보게 한다.
- **작동 단계**: 첫 단계. 분해하면 "$G$는 극솟값에서만 끊긴다"와 "포물선 $h$가 그 값에 위에서 접한다"로 바로 번역된다.
- **대표 기출**: J27-21. $f(\alpha)=f'(t)-4t^2+4$, "$t=3$에서만 불연속", 답 11. $-4t^2$가 $h$를 위로 볼록하게 뒤집는 장치이다.
- **레시피**: 내부 함수 $h$를 이차식으로 만들어 꼭짓점이 계수 하나와 일치하게 하고, 외부 함수의 불연속값(극솟값)에 접하게 한다. 템플릿: J27 21번 ⑧(답 $f(1)=5$).
- **적합 과목·번호대**: 미적분Ⅰ 28(단답 킬러).
- **흔한 실패**: 계수 선택에 따라 $h$가 일차식이 되면 "한 점에서만 불연속"이 자동으로 성립해 조건이 무력해진다(J27-21 조건 역할표).

### P5. 숨은 대칭·평행이동·닮음
- **정의**: 두 곡선(또는 같은 곡선의 두 부분)이 대칭이동, 평행이동, 닮음 관계에 있다. 이 관계를 밑, 계수, 인수분해 표기로 가려 두고 발견하게 한다.
- **작동 단계**: 발견형 관문 하나에 전부 걸린다. 보면 계산이 짧고, 못 보면 진행할 수 없다. 정답률이 양극화된다.
- **대표 기출**:
  - C26-22: 곡선2 = 2 × (곡선1의 $y=x$ 대칭), 답 457.
  - S27-22: 직선 $y=x-\frac14$ 대칭 = $(1,-1)$ 평행이동이 일치하는 직선, 답 97.
  - S27-20: $g$의 $x=\pi$ 대칭, 답 17.
  - E28-28: $x(x-1)^2(x-2)$ = $x=1$ 대칭 4차.
  - E28-30: 같은 밑 3, 같은 계수 6이 동치를 만든다.
- **레시피**:
  1. 깔끔한 기본형을 정한다(예: $y=4^{x-1}-\frac12$, 배율 2).
  2. 변환된 곡선을 계산한다(역함수·이동).
  3. 결과를 다른 밑·계수로 다시 써서 관계를 숨긴다($\log_{16}(8x+2)$).
  4. 점은 진수가 밑의 거듭제곱이 되도록 고른다.
  5. 묻는 값은 $p+q$나 $a^3$으로 정수화한다.
- **적합 과목·번호대**: 대수 30(단답 킬러), 지수·로그. 삼각함수형은 빈칸 추론과 결합해 4점 보통.
- **흔한 실패**: 관계를 너무 노출하는 경우(예: $y=\log_2(x+2)$와 $y=2^x-2$ → 바로 보임). 반대로 다른 조건만으로 해가 결정되어 관계를 몰라도 수치로 풀리는 경우. C26-22는 중점만으로 해가 유일하지만 손으로는 풀 수 없게 만들어 관계를 '풀이 열쇠'로 남겼다.

### P6. 문자 이중 역할·자기참조
- **정의**: 함수의 상수 $a,b$가 동시에 교점 좌표가 되게 하는 장치. 조건이 짧은데 해석이 어렵다.
- **대표 기출**: E28-30. $f$의 상수 $a,b$와 교점 집합 $\{0,a,b,c\}$, $|c|=2|b|$, 답 90.
- **레시피**: E28 30번 ⑥ 참고.
  1. 직선과 로그곡선의 깔끔한 두 교점(3, 9)에서 출발한다.
  2. 다른 조각을 역함수꼴로 설계한다.
  3. 상수를 문자로 숨긴다.
  4. 연속 해족 중 하나를 고르는 비율 조건($|c|=2|b|$)을 단다.
  - 템플릿: $B=2$, $m=4$ → 답 80.
- **적합 과목·번호대**: 대수 30.
- **흔한 실패**: 해족 중 비정수 후보가 남아 있는데 그것을 제거하는 조건이 없는 경우. E28-30에서 $|c|=2|b|$를 빼면 $b\approx2.478$ 후보가 남는다.

### P7. 케이스 분류 + 단서·계수로 제거
- **정의**: 필요조건으로 후보 케이스를 2~4개 만들고, 단서·부호·홀짝·범위로 하나씩 지운다. "최댓값과 최솟값", "모든 순서쌍"처럼 **모든 케이스를 끝까지 찾게 하는 질문**과 짝을 이룬다.
- **작동 단계**: 후반부. 케이스 누락이 실패 원인이다. 누락해도 정수가 나오면(S27-21의 576, 3, 108) 단답에서 스스로 알아챌 수 없다 → 강한 변별.
- **대표 기출**:
  - C26-21: $t\in\{0,2,\beta\}$. 계수 $-\frac72$의 음수 부호가 $t=0$ 케이스를 지운다.
  - S27-21: $a\in\{1,3\}$ / $a=2$, 최댓값 × 최솟값.
  - E28-16: $b=1,2,3$, $M+m$.
  - J27-14: 개수 $\{2b,3b,4b\}$ 중 홀수 15로 확정.
  - C26-28: 홀짝 필터로 한 경우 제거.
- **레시피**:
  1. 케이스를 낳는 자유 요소(경계 위치 $t$, 매개변수 범위)를 하나 둔다.
  2. 케이스마다 결과를 계산한다.
  3. 남길 케이스만 살아남도록 **계수 하나에 두 역할**(값 조정 + 케이스 제거)을 맡긴다.
  4. 단서는 남은 모호함 하나를 지우는 데만 쓴다.
- **적합 과목·번호대**: 모든 킬러 슬롯(20, 21, 28, 29, 30)과 준킬러 16.
- **흔한 실패**: 단서가 실제로는 아무 해도 지우지 않는 경우. C26-21의 단서 $g(-1)\ne-\frac72g(1)$는 빼도 해가 늘지 않는다(안내용). 안내용 단서는 괜찮지만, 필요한 제거 조건을 단서로 착각하면 해 다수가 된다. 케이스가 5개 이상이면 계산 노가다가 된다.

### P8. 이산 구조 압축
- **정의**: 수열·합에서 직접 나열하면 너무 많은 경우(300개, 512까지)를 구조(정수성 판정, 재귀 나무, 양방향 전개, 짝짓기)로 압축하게 한다.
- **작동 단계**: 중간. 압축 발상이 관문이고, 이후 계산은 짧다.
- **대표 기출**:
  - S27-14: 정수성이 $\sum m^2 \bmod 5$로 줄어듦, 답 171.
  - J27-22: 씨앗 2개, $N(s)=N(s-1)+2N(s-4)$, 답 32.
  - E28-14: 가운데 항 $a_4$에서 양방향 전개, 답 16.
  - C26-20: $2a_{2k+1}+a_{2k+2}=2k+1$로 짝짓기, 답 130.
- **레시피**: 출발 구조(이진·삼진 전개, 법 $c$, 양방향 점화)를 먼저 정하고, 큰 상한이나 큰 목표값으로 나열을 막는다. 숨은 예외(씨앗 2개, $n\ge2$에서만 성립)를 하나 넣는다.
- **적합 과목·번호대**: 대수 14(5지 준킬러), 22~27 단답 대수, 30(킬러 가능).
- **흔한 실패**: 법이나 진법이 너무 단순해 규칙이 바로 보이는 경우(S27-14: 법 2·3은 너무 단순). 상한이 작아 나열로 풀리는 경우.

### P9. 주기 함수 근 개수
- **정의**: 삼각방정식의 실근 개수를 매개변수로 맞추게 한다. 한 주기당 근 수, 접점(1개), 닫힌구간 끝점(+1)이 함정이다.
- **대표 기출**:
  - E28-16: $|2\sin ax+b|=1$, 근 10개 → $(3,1),(5,2),(10,3)$, 답 17.
  - J27-14: 개수 $\{2b,3b,4b\}$, 15 → 답 7.
- **레시피**: 매개변수에 따라 개수식이 $\alpha a+\beta$ 꼴로 바뀌는 경우를 2~3개 만든다. 목표 개수를 일부 경우만 정수해를 갖도록(홀수, 6의 배수 등) 고른다. 템플릿: E28 16번 ⑧(답 20), J27 14번 ⑧(답 7).
- **적합 과목·번호대**: 대수 14·16(5지 준킬러).
- **흔한 실패**: 끝점·접점 처리 실수가 선지 안에 들어가지 않으면 함정이 무력하다(두 기출 모두 오답이 선지 밖이라 시간 손실로만 변별).

### P10. 보조 삼각형 연쇄 + 사인법칙
- **정의**: 원과 삼각형 그림에서 **반지름이 만드는 이등변**을 숨기고, 보조 삼각형을 2~3개 거쳐 사인법칙(외접원)으로 마무리하게 한다.
- **대표 기출**:
  - C26-14: △ACG → △AEG → △CEG, $\overline{GH}=2R\sin A$, 답 $\frac{32\sqrt{15}}{25}$.
  - E28-19: 이등변 APB·AQB, 120° 정수 삼각형 (3, 5, 7), 답 $\frac67$.
- **레시피**:
  1. 정수 또는 특수각 삼각형(3-4-5, 120°의 (3,5,7))에서 출발한다.
  2. 원의 반지름을 내분비 등으로 간접 제시한다.
  3. 길이 조건 하나로 점을 고정하고, 그 길이는 코사인 값이 단위분수가 되게 역산한다.
  4. 마지막에 원주각 → $2R\sin$으로 지름길을 둔다.
  - 템플릿: C26 14번 ⑧(GH $=\frac{2\sqrt{105}}5$), E28 19번 ⑧($\frac7{13}$).
- **적합 과목·번호대**: 대수 19(5지 준킬러).
- **흔한 실패**: 그림이 해를 하나로 정하지 못하는 경우. C26-14는 "호 EF 위"로 그림을 고정하지만, 검증해 보면 G 후보 두 개의 답이 같았다. 무리수 선지의 근호 종류로 답이 드러나는 경우도 실패이다(C26-14는 $\sqrt{15},\sqrt{10},\sqrt3$를 섞어 막음).

### P11. 빈칸 추론(안내형 4점)
- **정의**: 풀이 과정 박스의 빈칸 (가)(나)(다)를 채우고 조합한 값을 묻는다. 관문을 형식이 안내하므로 4점 중 쉬운 쪽이다.
- **대표 기출**:
  - C26-20: 130. 함정은 $n\ge2$에서만 성립하는 식.
  - S27-20: 17. 숨은 함정은 비워 둔 △AOD 식.
  - J27-20: 48.
  - E28-27: 7.
- **레시피**: 빈칸 하나에 실질적 관문(예외 범위, 대칭)을 숨기고, 마무리 연산 $\frac{p\cdot q}{f(12)}$ 등으로 세 빈칸을 모두 확인하게 한다.
- **적합 과목·번호대**: 2028 체제의 27번(단답 4점 보통, 대수).
- **흔한 실패**: 마무리 연산이 실수를 흡수하는 경우. J27-20의 $(pqr)^2$은 부호 실수를 흡수해 오답도 정답이 된다 → 짝수 거듭제곱 마무리는 피한다.

### P12. 시행의 상태 압축(확통)
- **정의**: 반복 시행을 "상태와 중립 이동", "두 상자에서 동시에 소거되는 변수", "여집합 쌍", "홀짝 불변량"으로 압축하게 한다. 압축하지 못하면 $6^4=1296$가지를 추적해야 한다.
- **대표 기출**:
  - C26-28: 눈 6이 상자 2·3에서 소거, 경우 2개, $\frac3{16}$.
  - S27-28: 상태별 중립 집합, 3의 짝수 번, $\frac{69}{371}$.
  - J27-28: 여집합 쌍 $S_{2i-1}, S_{2i}$, $\frac{10}{81}$.
- **레시피**:
  1. 시행 규칙을 집합 연산으로 설계해 대부분의 결과가 중립이 되게 한다.
  2. 사건을 불변량(차이, 홀짝)으로 정의한다.
  3. 조건부확률의 분모를 홀짝 필터로 둔다.
  4. 반복 횟수는 경우가 2~4개 남는 최소값으로 정한다(J27-28: 3번·5번이면 확률 0, 2번이면 너무 쉬움).
- **적합 과목·번호대**: 확통 21(5지 킬러) 또는 29(단답).
- **흔한 실패**: 반복 횟수의 홀짝이 맞지 않아 확률이 0이 되는 경우(J27-28의 변형 3회·5회). 근접 선지가 없으면 한 경우를 누락해도 거르지 못한다(S27-28은 분모 371/373, 분자 69/71/73으로 촘촘하게 배치).

### P13. 칸막이·틈 배치(확통, 원순열 대체)
- **정의**: 일렬 배치의 이웃 조건을 "중립 원소가 만드는 칸", "특정 원소를 지운 열에 다시 끼우기"로 바꾼다. 원순열 없이 확통 킬러를 만드는 핵심 장치이다.
- **대표 기출**:
  - E28-21: 1을 지운 0·2 열, 교대 칸, 144.
  - J27-30: 검은 공이 칸막이, 780.
  - C26-30: 2를 0 또는 벽 사이 틈에 넣음, 112 + 150 = 262.
- **레시피**:
  1. 중립 원소(1, 검정, 0)와 서로 배척하는 원소를 정한다.
  2. 개수를 정해 칸 수 제약이 실제로 작동하게 한다(J27-30: 칸 수 < 노랑 + 보라).
  3. 개수 조건을 "○개 또는 △개"로 주어 서로 다른 기법(블록, 틈)을 섞는다(C26-30).
  - 템플릿: E28 21번 ⑧(405), J27 30번 ⑧(162), C26 30번 ⑧(184).
- **적합 과목·번호대**: 확통 21(5지 마지막) 또는 29·30(단답).
- **흔한 실패**: 벽(양 끝)을 이웃 없음으로 볼지 모호한 경우. C26-30은 "이웃한 주머니"로 처리했고, 끝을 불허하면 101이 된다. 칸 배정 중복 계산 위험, 경우 10개 이상으로 커지면 노가다가 된다.

### P14. 표본공간 축소·분포표·여사건(확통)
- **정의**: 조건부확률의 조건으로 표본공간을 줄이거나(곱이 홀수 → $3^5$), 합의 분포표로 81가지를 5×5로 줄인다. 또는 여사건으로 세기 쉬운 쪽을 센다.
- **대표 기출**:
  - E28-29: $\frac{12}{31}$, 43.
  - J27-29: $\frac{17}{81}$, 98.
  - S27-29: 여사건 95 + 예외 1, 190.
  - C26-29: 전확률 $\frac{a+4}{32}$, 977.
- **레시피**: 대칭 분포(1-2-3-2-1), 상한 있는 중복조합(가운데 계수)처럼 계산이 깔끔한 구조에서 출발한다. "거의 자명한 조건의 예외 1개"(S27-29의 $10a\ge d$)로 꼼꼼함을 시험할 수 있다.
- **적합 과목·번호대**: 확통 26·29(단답).
- **흔한 실패**: 오답이 그럴듯한 정수로 나와(J27-29의 41, S27-29의 191) 준킬러인데 실제 오답률이 지나치게 높아지는 경우. 의도한 것인지 확인할 것.

### P15. 기댓값·분산 식 위장(확통)
- **정의**: Σ 표기 안에 $E(X^2)$를 숨기거나, 기댓값 조건이 확률이 아닌 매개변수(값의 범위 $k$, 시행 매개변수 $a$)를 정하게 한다.
- **대표 기출**:
  - S27-30: $\sum k^2P(\overline X=\frac k5)=25E(\overline X^2)$, 170.
  - E28-26: $E(X^2)=2E(X)$ → $k=3$. 확률 합 함정 $H_k$, 25.
  - C26-29: $E(X)=4800$ → $a=4$.
- **레시피**: 확률질량함수를 $\frac bx$ 같은 꼴로 두어 기댓값이 깔끔하게 정리되게 하고, 확률의 합만 다른 꼴(조화합)이 되게 해 함정을 만든다. 단서 "$a,b$는 양수"가 오답(확률 합을 $a+bk$로 둔 경우 $a=0$)을 검출한다.
- **적합 과목·번호대**: 확통 26(단답 준킬러). 모비율 버전은 §3 참고.
- **흔한 실패**: 조화합 등이 커져 단답 수준을 넘는 경우(E28-26 템플릿 $c=4$: $p+q=617$, 실전용은 $c\le3$).

### P16. 마무리 정수화 + 오류 검출 설계(공통 부속 장치)
- **정의**: 마지막 연산으로 무리수·분수·부호를 지워 단답을 자연수로 만든다. 동시에 오답 경로가 비정수, 단서 모순, 선지 밖 값으로 떨어지게 해서 **시간으로 변별**한다.
- **관찰된 정수화**: $a+20k^2$, $a^2+b^2$ (E28); $p+q$ (E28-26·29, C26-22, J27-29); $\frac{pq}{f(12)}$ (C26-20); $3\cdot\frac{p}{q}$ (S27-20); 최댓값 × 최솟값 (S27-21); $6a$ (S27-30); $1000k$ (C26-29).
- **오류 검출의 두 방향**:
  - 완화(막힘형): 오답이 비정수·모순·선지 밖이 되게 한다(J27-14, J27-15, C26-15, C26-20, E28 5지 대부분).
  - 강화(확신형): 오답도 정수가 나오게 한다(S27-21, J27-22, J27-29). 킬러에만 쓴다.
- **선지 설계 관찰**: 2028 예시와 C26은 대부분 **등간격** 선지라 대표 오답이 선지 밖에 있다. S27-15는 방향 착오 값을 ①에 넣었고, S27-28은 근접 분수로 정확성을 요구했다.

### 슬롯별 장치 조합 원칙
1. **5지 끝(20·21)은 계산이 적고 관점 전환 하나**: E28-20(무계산형), E28-21(구조를 보면 3분 안에 끝남).

## 4. 4점 문항 출제 체크리스트

문항 파일(`items/q<번호>.md`)을 넘기기 전에 모두 확인한다. 검증 스크립트는 `analysis/discrimination/scripts/`와 같은 방식으로 작성해 문항 옆이나 `review/`에 둔다.

### A. 해의 유일성
- [ ] 조건을 만족하는 함수·배치·매개변수를 **전수 또는 기호 연립**으로 모두 찾았다. 예: C26-21은 $t$ 케이스 × $\beta$ 구간 × 대입 순서를 전수 탐색했다. S27-21은 $p,q,a$ 격자를 전수 탐색했다.
- [ ] 함수가 유일하지 않으면, 묻는 값이 **불변량**임을 확인했다(E28-20 방식). 존재 예시 하나를 수치로 제시했다.
- [ ] 수치 근(초월방정식)이 있으면 단조성·볼록성으로 근의 개수를 증명하거나 스캔했다(C26-22의 $F(s)$ 단조, S27-22의 $a$ 스캔).

### B. 모든 조건의 필요성 (하나씩 빼 보기)
- [ ] 조건마다 "빼면 해가 어떻게 늘어나는지"를 표로 적었다(각 문서 ⑥의 '조건별 역할' 표 형식).
- [ ] 아무 해도 지우지 않는 조건은 **안내용**인지 명시했다. 예: C26-21의 단서는 안내용이다. 의도치 않은 중복 조건이면 지운다.
- [ ] 단서 조건이 대표 오답 하나와 모순되어 오류 검출기 역할을 하는지 확인했다(E28-26 "a 양수" → 오답 $a=0$ 차단).

### C. 오답 경로와 선지 설계 (5지)
- [ ] 대표 오답 2~4개를 실제로 계산했다(스크립트에 `wrong:` 줄로 남긴다).
- [ ] 선지 방침을 정했다.
  - 등간격(오답을 선지 밖으로 → 시간 변별): E28, C26 대부분.
  - 방향 착오 값을 1개 넣기: S27-15 ①.
  - 근접값(정확성 요구): S27-28, E28-21.
- [ ] 정답이 선지 위치·근호 종류로 드러나지 않는다(C26-14의 근호 혼합).

### D. 정답 형태 (단답)
- [ ] 답은 0~999의 자연수이다(`analysis/2028-example.md` 유형 관례: 단답은 자연수, 3자리 이하).
- [ ] 마무리 연산을 **먼저** 정하고 수치를 역산했다(S27 요약 2번). 분수는 "$\frac qp$일 때 $p+q$ (단, $p$와 $q$는 서로소인 자연수이다.)".
- [ ] 마무리 연산이 실수를 흡수하지 않는다. 짝수 거듭제곱 $(\cdot)^2$은 부호 실수를 흡수하므로 피한다(J27-20).
- [ ] 오답이 비정수가 되는지(막힘형) 정수가 되는지(확신형) 의도대로 설계했다. 확신형은 킬러에만 쓴다.

### E. 범위와 형식
- [ ] 대수·미적분Ⅰ·확률과 통계 범위 안이다. 원순열을 쓰지 않았다. 정규근사를 쓰면 성취기준을 확인했다.
- [ ] 발문·단서·조건 박스·배점 표기가 2028 관례를 따른다(`analysis/2028-example.md` §2 유형 관례, §3.5).
- [ ] 그림이 해를 하나로 고정하거나, 그림 없이도 조건만으로 해가 정해진다. 그림 의존 조건(예: "호 EF 위")은 답에 미치는 영향을 확인했다.

### F. 검증 스크립트 첨부
- [ ] 정답, 유일성 탐색, 조건 제거 실험, 오답 값을 한 스크립트에서 출력한다. 실행법은 `pip install sympy` 기준으로 상단 주석에 적는다.

### 4점 문항 작업자(문항 하나 담당)
1. 설계표에서 내 슬롯의 패턴과 참고 템플릿을 확인하고, §1의 해당 패턴 항목과 대표 기출의 상세 문서 ⑥(역설계), ⑧(템플릿)을 읽는다.
2. 템플릿을 그대로 쓰지 말고 **파라미터를 바꾼다**. 각 ⑧ 절의 '바꿀 파라미터'와 '수치 선택 방법'을 따른다. 기출 템플릿의 검증 세트 수치를 그대로 내면 기출 변형이 되므로, 새 수치를 골라 스크립트로 다시 확인한다.
3. 조건별 역할표를 먼저 쓰고(무엇을 고정하는지, 빼면 어떻게 되는지) 문항을 쓴다.
4. 슬롯의 목표(관문 수, 단계 수, 계산량)를 넘으면 §5의 '쉽게' 레버를, 못 미치면 '어렵게' 레버를 하나만 적용한다.
5. §4 체크리스트를 통과시키고, 검증 스크립트와 함께 넘긴다.
6. 설계를 바꿨으면 `design/blueprint.md`도 고치고 공지한다(보드 규칙).
