# 2026학년도 수능 수학 분석 (2022 개정 과목 대응)

- 원본: `sources/2026-csat.pdf` (홀수형, 12쪽). **공통(1~22) + 선택 확률과 통계(23~30)만** 들어 있음. 미적분·기하 선택 문항은 원본에 없음.
- 2015 개정 과목 → 2022 개정 대응: 수학Ⅰ → **대수**, 수학Ⅱ → **미적분Ⅰ**, 확률과 통계 → **확률과 통계**(2028 수능에서 공통).
- 보드 규칙(`meta/rules`)의 출제 범위: 대수·미적분Ⅰ·확률과 통계, **원순열 제외**, **모비율의 추정 포함**.
- 대응 표기: ✅ 그대로 대응 · ⚠️ 대응되나 주의 · ❌ 범위 밖.
- 체감 난이도: 하 / 중하 / 중 / 중상 / 상(준킬러) / 최상(킬러). 정답은 직접 풀어서 확인함.

## 4. 출제 경향

1. **앞 번호 계산 문항은 교과서 기본형**: 지수법칙, 미분계수 정의, ∑ 선형성, 연속, 곱의 미분, 로그, 두 곡선 사이 넓이, 삼각함수 부호. 한 단계 계산으로 끝남.
2. **9~13번(4점 중간)**: 개념 하나 + 계산 두세 단계. 9(극값과 접선), 10(지수함수 점근선+도형), 11(〈보기〉 속도·거리), 12(등비수열 간격 합), 13(접선 두 개로 넓이).
3. **도형 준킬러(14번)**: 사인·코사인법칙을 원 두 개와 원주각으로 엮음. 그림 제공, 보조원(외접원)의 반지름을 구해 사인법칙으로 마무리.
4. **정적분 함수 준킬러(15번)**: 구간별 정의 함수 차의 부호 변화 = 극값 개수. "조건을 만족하는 a의 최댓값"을 묻는 추론형.
5. **빈칸 추론(20번)**: 수열의 합 Sₙ에서 일반항 관계식 유도 과정의 빈칸. 수학적 귀납법이 아닌 Sₙ₊₁−Sₙ 형태.
6. **킬러 2문항(21, 22)**
   - 21: 구간별로 부호가 바뀌는 g(x)=±f(x), 우극한 존재 조건(가)와 음수가 되는 자연수 집합(나). **조건을 다항식 인수(근)로 번역 → 경계 t의 위치로 케이스 분류**가 핵심. 집합 원소를 g(−1), −7/2·g(1) 같은 함숫값으로 주어 연립하게 함.
   - 22: 지수·로그 곡선 위 두 점, 직선 y=x 대칭, 원점을 지나는 직선, 중점 좌표. **식이 복잡해 보이지만 중점 조건만으로 값이 깔끔하게 결정**(a=63/4, b=7/4). 그래프 해석보다 대입·검산 위주.
7. **확통**: 23~27 기본, 28(조건부확률+경우 분류), 29(이항분포→정규근사, 표 제공), 30(개수 제한 분배+이웃 조건 세기)이 고난도.

- 공통 킬러는 **미적분Ⅰ 21번(함수 추론)과 대수 22번(지수·로그 그래프)** 한 문항씩. 2022 개정 모의고사에서도 같은 축(미적분Ⅰ 함수 추론 1 + 대수 1)을 유지하고, 확률과 통계가 공통이 되므로 28~30 고난도도 공통 4점으로 흡수해 배치할 필요가 있음.
- 원순열이 빠져도 이번 30번처럼 배치·분할로 고난도 경우의 수를 만들 수 있음. 모비율의 추정은 이번 시험에 없으므로 별도 문항(3점 또는 4점)으로 보충 권장.
