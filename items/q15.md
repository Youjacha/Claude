# q15 — 미적분Ⅰ · 수직선 위 점의 속도와 가속도(운동 방향이 바뀌는 시각)

- 배점: 4점 · 형식: 5지선다 · 목표 난이도: 중 · 목표 정답률: 55~70%
- 설계표 행: design/blueprint.md §1 15번 · 작업: M1-16
- 참고 기출: 2028-15(위치 다항식 → 속도·가속도 값), 2026-11(운동 방향 전환 = 속도 부호 변화), 2027-09-9(수직선 위 운동). 빌린 것: “위치 → 속도 → 가속도” 틀과 방향 전환 판단. 바꾼 것: 사차 위치함수, 속도가 0인 시각 둘 중 하나에서만 방향이 바뀌는 구조(중근)를 관문으로 삼음. 수치·함수는 모두 새로 정함.

## 문항

수직선 위를 움직이는 점 P의 시각 $t\ (t \ge 0)$에서의 위치 $x$가
$$x = t^4 + at^3 + bt^2 + ct$$
이다. 점 P가 다음 조건을 만족시킬 때, 시각 $t=4$에서 점 P의 가속도는? (단, $a$, $b$, $c$는 상수이다.) [4점]

> (가) 시각 $t=1$과 시각 $t=3$에서 점 P의 속도는 $0$이다.
> (나) $t>0$에서 점 P의 운동 방향이 바뀌는 시각은 오직 하나이다.
> (다) 시각 $t=2$에서 점 P의 속도는 양수이다.

## 선지
① $28$ ② $36$ ③ $44$ ④ $52$ ⑤ $60$

## 정답
① 28

## 해설
점 P의 시각 $t$에서의 속도를 $v(t)$라 하면 $v(t) = 4t^3 + 3at^2 + 2bt + c$ 이다.
1. (가)에서 $v(1)=v(3)=0$이고 $v$는 최고차항의 계수가 $4$인 삼차함수이므로, 나머지 한 근을 $r$라 하면 $v(t)=4(t-1)(t-3)(t-r)$.
2. **운동 방향이 바뀐다 ⇔ 속도의 부호가 바뀐다.** 속도가 $0$이어도 그 시각이 $v$의 중근이면 부호가 바뀌지 않는다.
   - $r\le 0$이면 $t=1$, $t=3$에서 모두 방향이 바뀐다(두 번).
   - $r>0$이고 $r\ne1$, $r\ne3$이면 세 번 바뀐다.
   - $r=1$이면 $v=4(t-1)^2(t-3)$: $t=3$에서만, $r=3$이면 $v=4(t-1)(t-3)^2$: $t=1$에서만 바뀐다.
   
   따라서 (나)에서 $r=1$ 또는 $r=3$.
3. (다) $v(2)=4\cdot1\cdot(-1)\cdot(2-r)=4(r-2)>0$이므로 $r>2$, 즉 $r=3$. 
   ($r=1$이면 $v(2)=-4<0$.)
4. $v(t)=4(t-1)(t-3)^2$이므로 가속도는
   $v'(t)=4(t-3)^2+8(t-1)(t-3)=4(t-3)(3t-5)$.
5. $t=4$에서 가속도는 $4\cdot1\cdot7=28$.

## 출제 의도·변별 장치
- 패턴 태그: [번역] 1단계 (README P3 부호 변화의 미분 버전) + 가벼운 [분류]
- 관문: 1) (가)를 “속도 = $4(t-1)(t-3)(t-r)$”로 쓰기(최고차항 계수 4 확인) 2) “방향이 바뀌는 시각이 하나” ⇒ 속도가 0인 두 시각 중 하나는 **중근**(부호 불변)이라는 번역 3) (다)로 두 후보 중 하나 고르기.
- 예상 오답 경로와 결과 값:
  - (다)를 쓰지 않거나 부호를 잘못 판단해 $v=4(t-1)^2(t-3)$을 택함 → $v'(t)=4(t-1)(3t-7)$, $v'(4)=60$ → 선지 ⑤
  - 가속도 대신 속도 $v(4)=12$를 답함 → 선지 밖
  - 최고차항 계수 4를 빠뜨려 $v=(t-1)(t-3)^2$로 계산 → $7$ → 선지 밖
  - “속도가 0이면 방향이 바뀐다”로 오해하면 (가)·(나)가 모순처럼 보여 진행 불가 → 재검토 유도
- §3 중복 금지 점검: 관문은 속도 부호 변화(중근 판별)이고 정적분·이동 거리를 쓰지 않음(20과 분리). 극값 조건으로 미정계수를 구하는 25(3점)와 달리 함수 극값이 아닌 운동 방향을 묻고, 위치함수 $t^4-\frac{28}{3}t^3+30t^2-36t$는 다른 문항 함수와 다름.

## 조건별 역할
| 조건 | 하는 일(제거하는 자유도·케이스) | 빼면 생기는 일 |
|---|---|---|
| (가) | 속도의 두 근을 1, 3으로 고정 → 자유도는 나머지 근 $r$ 하나 | 속도의 근이 자유로워 답이 여럿(검증: 여러 값) |
| (나) | $r$을 $\{1,3\}$으로 제한(중근 번역) | $r>2$인 모든 $r$가 가능 → 답이 여럿 |
| (다) | 두 후보 $r=1$, $r=3$ 중 $r=3$ 선택 | 답이 28 또는 60 → 하나로 정해지지 않음 |
| 단서($a,b,c$ 상수) | 위치함수의 꼴 고정(사차, 최고차항 계수 1, $x(0)=0$) | – (형식 단서) |
