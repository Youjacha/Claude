# q19 — 대수 · 삼각함수: 사인법칙·코사인법칙 (원에 내접하는 삼각형과 호의 중점)

- 배점: 4점 · 형식: 5지선다 · 목표 난이도: 중상 · 목표 정답률: 30~45%
- 설계표 행: design/blueprint.md §1 19번 · 작업: M1-20
- 참고 기출: 2028-19(원이 만든 이등변 발견 → 코사인법칙 연쇄, 단서로 점 하나 지우기), 2026-14(원주각 → 외접원 반지름을 사인법칙으로). 빌린 것은 “이등변·원주각 발견 + 보조 삼각형 순서 + 단서” 골격뿐이고, 상황(원 위의 점이 만든 이등변삼각형 → 각의 이등분 발견 → 두 코사인법칙의 차)과 수치(6, 4, $3\sqrt3$)는 새로 정했다. 두 기출과 수치·서술이 겹치지 않는다.

## 문항

그림과 같이 원 $O$에 내접하는 삼각형 $\mathrm{ABC}$에서 $\overline{\mathrm{AB}}=6$, $\overline{\mathrm{AC}}=4$이다. 원 $O$ 위의 점 $\mathrm{D}$가

$$\angle\mathrm{DBC}=\angle\mathrm{DCB},\qquad \overline{\mathrm{AD}}=3\sqrt3$$

을 만족시킬 때, 원 $O$의 반지름의 길이는? (단, 점 $\mathrm{D}$는 점 $\mathrm{A}$를 포함하지 않는 호 $\mathrm{BC}$ 위의 점이다.) [4점]

그림(`items/fig/q19.svg`, 흑백 선화): 원 $O$ 위쪽 오른편에 A, 아래쪽에 가로 현 BC(왼쪽 B, 오른쪽 C), BC 아래 호 위에 D. 선분 AB, BC, CA, AD, BD, CD가 그려져 있다.
좌표(그림 확정용, 문제에는 쓰지 않음): $\mathrm B\left(-\tfrac53,0\right)$, $\mathrm C\left(\tfrac53,0\right)$, $\mathrm A\left(3,\tfrac{8\sqrt2}{3}\right)$, $\mathrm D\left(0,-\tfrac{\sqrt2}{3}\right)$, 원의 중심 $\left(0,\tfrac{23\sqrt2}{12}\right)$, 반지름 $\tfrac{9\sqrt2}4$.

## 선지
① $\dfrac{9}{10}$ ② $\sqrt3$ ③ $\dfrac{3\sqrt3}{2}$ ④ $\dfrac{9\sqrt2}{4}$ ⑤ $\dfrac{9\sqrt2}{2}$

## 정답
④ $\dfrac{9\sqrt2}{4}$

## 해설
1. **이등변 → 원주각.** $\angle\mathrm{DBC}=\angle\mathrm{DCB}$이므로 $\overline{\mathrm{DB}}=\overline{\mathrm{DC}}=x$이다. 원주각의 성질에서 호 $\mathrm{DC}$에 대해 $\angle\mathrm{DAC}=\angle\mathrm{DBC}$, 호 $\mathrm{DB}$에 대해 $\angle\mathrm{DAB}=\angle\mathrm{DCB}$이다(단서에 따라 A와 D는 현 BC의 서로 반대쪽에 있다). 따라서 $\angle\mathrm{BAD}=\angle\mathrm{CAD}=\theta$로 놓을 수 있다.
2. **보조 삼각형 두 개에 코사인법칙.**
   삼각형 ABD: $x^2=36+27-2\cdot6\cdot3\sqrt3\cos\theta=63-36\sqrt3\cos\theta$
   삼각형 ACD: $x^2=16+27-2\cdot4\cdot3\sqrt3\cos\theta=43-24\sqrt3\cos\theta$
3. 두 식을 빼면 $20=12\sqrt3\cos\theta$, 즉 $\cos\theta=\dfrac{5\sqrt3}{9}$이고, $x^2=63-60=3$, $x=\sqrt3$이다.
4. $\sin\theta=\sqrt{1-\dfrac{75}{81}}=\dfrac{\sqrt6}{9}$.
5. **사인법칙.** 원 $O$는 삼각형 ABD의 외접원이므로 $2R=\dfrac{\overline{\mathrm{BD}}}{\sin\theta}=\dfrac{\sqrt3}{\sqrt6/9}=\dfrac{9}{\sqrt2}$, 따라서 $R=\dfrac{9\sqrt2}{4}$. (참고: $\overline{\mathrm{BC}}=2x\cos\theta=\dfrac{10}{3}$, $\cos A=\dfrac{23}{27}$.)

## 출제 의도·변별 장치
- 패턴 태그: [구조](이등변·원주각 발견) + [함정](단서) — README P10(보조 삼각형 연쇄 + 사인법칙).
- 관문:
  1. “$\angle\mathrm{DBC}=\angle\mathrm{DCB}$”를 변의 조건($\mathrm{DB}=\mathrm{DC}$)이 아니라 **원주각을 통해 A에서의 각의 이등분**($\angle\mathrm{BAD}=\angle\mathrm{CAD}$)으로 옮기는 것. 이 발견 없이는 미지수가 너무 많아 막힌다.
  2. 같은 $\theta$와 같은 $x$를 공유하는 **두 보조 삼각형(ABD, ACD)** 을 골라 코사인법칙을 세우고 빼서 $\cos\theta$를 얻는 순서.
  3. 반지름을 삼각형 ABC가 아닌 **삼각형 ABD에서 사인법칙**으로 구하는 것(삼각형 ABC로 가면 $\cos A$를 구하려 배각 관계가 필요해 범위 밖 계산으로 막힌다).
- 예상 오답 경로와 결과 값:
  - $\sin\theta$ 대신 $\cos\theta$를 사인법칙에 넣음 → $\dfrac{9}{10}$ (선지 ①)
  - $x=\overline{\mathrm{BD}}$를 구하고 멈춤 → $\sqrt3$ (선지 ②)
  - D를 A의 대척점(AD를 지름)으로 착각 → $\dfrac{3\sqrt3}{2}$ (선지 ③)
  - 사인법칙에서 $\dfrac12$을 빠뜨려 $2R$을 답함 → $\dfrac{9\sqrt2}{2}$ (선지 ⑤)
  - 단서 무시(D를 A를 포함하는 호의 중점으로 둠: $\angle\mathrm{BAD}$와 $\angle\mathrm{CAD}$가 서로 보각이 되어 $\cos\theta'=\dfrac{\sqrt3}{9}$) → $R=\dfrac{9\sqrt{442}}{52}$ (선지 밖, 재검토 유도)

## 조건별 역할
| 조건 | 하는 일(제거하는 자유도·케이스) | 빼면 생기는 일 |
|---|---|---|
| 원 $O$에 내접, D가 원 $O$ 위 | 원주각으로 $\angle\mathrm{BAD}=\angle\mathrm{CAD}$를 만들고, 원 $O$를 삼각형 ABD의 외접원으로 만든다 | 이등분 관계가 사라져 D·R이 정해지지 않음(묻는 대상 자체가 사라짐) |
| $\overline{\mathrm{AB}}=6$, $\overline{\mathrm{AC}}=4$ | 두 보조 삼각형의 한 변. 차 $20=6^2-4^2$가 $\cos\theta$를 결정 | 다른 값이면 R이 달라짐(AB=5 → $R=\sqrt7$, AC=3 → $R=3$ 확인) |
| $\angle\mathrm{DBC}=\angle\mathrm{DCB}$ | D를 호 BC의 중점으로 고정 | D가 호 위를 움직여 R이 여러 값(9개 표본에서 모두 다름) |
| $\overline{\mathrm{AD}}=3\sqrt3$ | $\angle A$(삼각형의 모양) 고정 | $\angle A$가 자유로워 R이 연속적으로 변함 |
| 단서(A를 포함하지 않는 호 BC) | 이등분 대 외각 이등분 두 배치 중 하나를 지움 | R 후보가 $\dfrac{9\sqrt2}4$, $\dfrac{9\sqrt{442}}{52}$ 두 개 |

## 검증
- 해의 유일성: $\mathrm A(0,0)$, $\mathrm B(6,0)$, $\mathrm C(4\cos A,4\sin A)$로 놓고 $\angle A\in(0,\pi)$를 4000등분해 외접원과 호 BC(A 미포함)의 중점 D를 직접 구성, $\overline{\mathrm{AD}}-3\sqrt3$의 부호 변화를 전수 탐색 → 근 1개($\cos A=\tfrac{23}{27}$). sympy로 $\cos A=\tfrac{23}{27}$에서 $\mathrm{AD}^2=27$, $\mathrm{BD}=\mathrm{CD}=\sqrt3$, $\mathrm{BC}=\tfrac{10}3$, $R=\tfrac{9\sqrt2}4$를 정확히 확인.
