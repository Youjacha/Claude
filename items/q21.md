# q21 — 확률과 통계 · 조건 있는 배열의 경우의 수(칸막이·중복조합)

- 배점: 4점 · 형식: 5지선다 · 목표 난이도: 상 · 목표 정답률: 15~30%
- 설계표 행: design/blueprint.md §1 21번 · 작업: M1-22
- 참고 기출: 2028-21(중립 원소를 지운 열 + 교대 칸 비우기 골격을 빌림), 2027-06-30(중립 원소가 칸막이), 2026-30(이웃 금지 → 칸에 최소 1개). 바꾼 점: 카드 숫자 0·1·2 → 문자 A·B·C, 개수 (3, 3, 4), 이웃 쌍 개수 4, **같은 문자끼리의 이웃 금지 조건 (가)를 추가**해 칸의 성격을 세 가지(반드시 비움 / 반드시 채움 / 자유)로 나누고 AA 칸과 BB 칸의 비대칭을 관문으로 만들었다.

## 문항

문자 A, A, A, B, B, B, C, C, C, C가 하나씩 적혀 있는 10장의 종이가 있다. 이 10장의 종이를 모두 일렬로 나열할 때, 다음 조건을 만족시키도록 나열하는 경우의 수는? (단, 같은 문자가 적혀 있는 종이끼리는 서로 구별하지 않는다.)

> 왼쪽에서 $n\,(1\le n\le 10)$번째 자리에 놓인 종이에 적혀 있는 문자를 $x_n$이라 할 때,
> (가) $x_k$와 $x_{k+1}$이 모두 A인 자연수 $k\,(1\le k\le 9)$는 존재하지 않는다.
> (나) $x_k$와 $x_{k+1}$ 중 하나는 A이고 다른 하나는 B인 자연수 $k\,(1\le k\le 9)$의 개수는 4이다.

[4점]

## 선지
① 140 ② 145 ③ 150 ④ 155 ⑤ 160

## 정답
③ 150

## 해설
1. **C를 지운다.** C를 모두 지우면 A 3개, B 3개로 된 길이 6의 열(뼈대) $w$가 남는다. 거꾸로 $w$의 7개의 칸(양 끝 2칸 + 사이 5칸)에 C 4개를 나누어 넣으면 원래 배열이 하나씩 정해진다.
2. **칸의 성격을 정한다.** 이웃한 A와 B는 $w$에서 서로 다른 문자가 붙은 칸(교대 칸)에 C가 하나도 들어가지 않을 때만 생긴다. 따라서 (나) ⇔ “교대 칸 $T$개 중 **정확히 4개는 비우고**, 나머지 $T-4$개에는 C를 1개 이상”. (가) ⇔ “$w$의 AA 칸에는 C를 1개 이상”. BB 칸과 양 끝 칸은 **아무 제한이 없다**.
3. **뼈대 분류.** $T\ge4$, 즉 덩어리(같은 문자 연속) 수가 5 이상이어야 한다.
   - $T=5$: ABABAB, BABABA
   - $T=4$이고 B가 두 덩어리: ABABBA, ABBABA (BB 칸 1개)
   - $T=4$이고 A가 두 덩어리: BAABAB, BABAAB (AA 칸 1개)
4. **세기.** 비우는 칸 4개를 빼면 C를 넣을 수 있는 칸은 항상 3개이다.
   - $T=5$: 비울 교대 칸 4개를 고르는 방법 $\binom54=5$, 남은 교대 칸에 C 1개를 먼저 넣고 나머지 3개를 3칸에 분배 $\binom{5}{2}=10$ → $5\times10\times2=100$
   - BB 칸이 있는 뼈대: C 4개를 3칸(BB, 양 끝)에 자유롭게 $\binom{6}{2}=15$ → $15\times2=30$
   - AA 칸이 있는 뼈대: AA 칸에 C 1개를 먼저 넣고 나머지 3개를 3칸에 $\binom52=10$ → $10\times2=20$
5. 따라서 $100+30+20=150$.

- 예상 오답 경로와 결과 값:

  - (가)를 놓쳐 AA 칸을 자유로 둠 → 160 → 선지 ⑤

  - $T=5$에서 비울 칸 4개를 고르는 $\binom54$ 누락 → 70 → 선지 밖
  - $T=4$ 뼈대 누락 → 100 → 선지 밖
  - $T=5$에서 남은 교대 칸을 자유로 둠(C 0개 허용) → 200 → 선지 밖
- 선지는 간격 5로 촘촘하게 두어 마지막 두 경우(30, 20) 중 하나만 틀려도 걸러지게 했다.
- 중복 점검(§3): 확률로 묻지 않음, 원순열 없음, 카드·주머니·공·주사위 소재를 쓰지 않음(문자 배열). 3번(같은 것이 있는 순열 단순 계산), 12번(조합 확률)과 관문이 다르다.

## 조건별 역할
| 조건 | 하는 일(제거하는 자유도·케이스) | 빼면 생기는 일 |
|---|---|---|
| (가) A끼리 이웃 금지 | 뼈대의 AA 칸을 “반드시 채움”으로 바꾼다. AA 칸이 있는 뼈대 하나당 경우의 수를 $15\to10$으로 줄인다. | 답 160(⑤)으로 바뀜 |
| (나) A–B 이웃 4곳 | 교대 칸 4개를 비우게 하고 $T\ge4$ 뼈대만 남긴다(경우 3개). | 답 1960으로 바뀜 |
| 단서(같은 문자 비구별) | 같은 것이 있는 순열임을 확정 | 답이 $150\times3!\,3!\,4!=129600$으로 바뀜 |

## 검증
- 해의 유일성: 경우의 수 문항이므로 값은 하나. 10자리에 A·B·C를 놓는 서로 다른 배열 4200가지를 모두 만들어 두 조건을 직접 판정 → 150개(서로 다른 문자열 150개).
- 독립 계산: 뼈대 20가지마다 (교대 칸 수, AA 칸 수, BB 칸 수)로 중복조합 공식을 적용한 구조식 → 150, 전수 탐색과 일치. 경우별 $T=5$: 100, $T=4$: 50.
- 조건 필요성: (가) 제거 → 160, (나) 제거 → 1960, 비구별 단서 제거 → 129600. 모두 150과 다름.
- 선지: 오답 경로 6개를 구조식의 옵션으로 재현(140, 160, 160, 70, 100, 200). 140·160은 선지 ①·⑤, 나머지는 선지 밖, 어느 것도 150과 같지 않음.
