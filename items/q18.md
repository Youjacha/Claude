# q18 — 미적분Ⅰ · 함수의 극한 존재 조건 (근의 중복도·미정계수)

- 배점: 4점 · 형식: 5지선다 · 목표 난이도: 중상 · 목표 정답률: 30~45%
- 설계표 행: design/blueprint.md §1 18번 · 작업: M1-19
- 참고 기출: 2028-18(극한 존재 → 분자의 근과 중복도, 근 하나를 원점에 숨김), 2027-09-15(극한이 존재하는 매개변수 $t$의 집합 → 함수 역추적). 빌린 것: “극한이 존재하는 $t$를 센다”는 [역추적] 틀과 원점에 숨긴 근. 바꾼 것: 분모를 $t$에 따라 움직이는 $x^2-t^2$로 두어 **$t=0$일 때만 분모가 중근**이 되게 했고, 묻는 함수·수치·발문은 모두 새로 정했다.

## 문항

최고차항의 계수가 1인 삼차함수 $f(x)$가 다음 조건을 만족시킬 때, $f(5)$의 값은? [4점]

> (가) $\displaystyle\lim_{x\to t}\frac{f(x)}{x^2-t^2}$의 값이 존재하도록 하는 실수 $t$의 개수는 $1$이다.
> (나) $\displaystyle\lim_{x\to 0}\frac{f(x)}{x}$의 값이 존재한다.
> (다) $\displaystyle\lim_{x\to\infty}\frac{f(x)-x^3}{x^2}=-4$

## 선지
① $25$ ② $45$ ③ $65$ ④ $85$ ⑤ $105$

## 정답
② 45

## 해설
1. (다)에서 $f(x)-x^3$의 $x^2$의 계수가 $-4$이고, (나)에서 $x\to0$일 때 분모가 $0$으로 가므로 $f(0)=0$이다. 따라서 $f(x)=x(x^2-4x+c)$로 놓을 수 있다.
2. (가)를 번역한다. $x\to t$일 때 분모 $x^2-t^2\to0$이므로 분자도 $0$으로 가야 한다.
   - $t\neq0$이면 $x^2-t^2=(x-t)(x+t)$에서 $x+t\to2t\neq0$이므로 $x=t$는 분모의 **단순근**이다. 극한이 존재할 필요충분조건은 $f(t)=0$이다.
   - $t=0$이면 분모가 $x^2$이 되어 $x=0$은 **중근**이다. 극한이 존재할 필요충분조건은 $f(x)$가 $x^2$으로 나누어떨어지는 것, 즉 $c=0$이다.
   - 따라서 극한이 존재하는 $t$의 집합은 ($f$의 $0$이 아닌 서로 다른 실근) $\cup$ ($c=0$일 때만 $\{0\}$)이다.
3. $c=0$이면 $f(x)=x^2(x-4)$이고 $t=0,\ 4$에서 극한이 존재하므로 $t$가 $2$개 → 모순.
4. $c\neq0$이면 $f(0)=0$이어도 $0$은 단순근이라 $t=0$에서는 극한이 존재하지 않는다. $t$는 $x^2-4x+c=0$의 실근뿐이고, 개수가 $1$이려면 중근이어야 하므로 $16-4c=0$, $c=4$이다.
5. $f(x)=x(x-2)^2$ (이때 극한이 존재하는 $t$는 $2$ 하나, 극한값 $0$). $f(5)=5\times9=45$.

## 출제 의도·변별 장치
- 패턴 태그: [번역] [역추적] (보조: [함정] — $t=0$ 점검)
- 관문:
  1) **분모가 $t$에 따라 바뀐다**는 것의 번역: $t\neq0$이면 단순근(→ $f(t)=0$), $t=0$이면 중근(→ $x^2\mid f$). 같은 식이 $t=0$에서만 다른 조건을 요구한다.
  2) **$f(0)=0$인데도 $t=0$은 집합에 들지 않을 수 있다**는 것: (나)가 $0$을 근으로 주므로 “$0$은 당연히 들어간다”고 세면 해가 없거나 무수히 많아져 막힌다.
  3) [역추적] “개수가 $1$” → 남은 이차식이 중근 → $c=4$. 반대로 $c=0$일 때 생기는 $t=0$을 빠뜨리면 $x^2(x-4)$도 해처럼 보인다.
- 예상 오답 경로와 결과 값:
  - W1: $t=0$을 따로 점검하지 않고 “$x^2-4x+c$의 $0$이 아닌 근이 하나”만 확인 → $c=0$인 $f=x^2(x-4)$도 채택 → $f(5)=25$ → **선지 ①**
  - W2: (나)를 버리고 (가)를 “실근이 하나뿐 = 삼중근”으로 처리 → $f=\left(x-\frac43\right)^3$ → $f(5)=\frac{1331}{27}$ → 비정수, 선지 밖(재검토 유도)
  - W3: (다)에서 $x(x-r)^2$의 $x^2$ 계수 $-2r=-4$를 부호 실수 → $r=-2$, $f=x(x+2)^2$ → $245$ → 선지 밖
  - W4: $x^2$ 계수를 $-r$로 착각 → $r=4$, $f=x(x-4)^2$ → $5$ → 선지 밖
  - W5: $f(0)=0$이면 $t=0$이 항상 집합에 든다고 오판 → $c=4$일 때 $t$가 $\{0,2\}$로 2개라 보고 버림, $c>4$이면 모두 해처럼 보여 답이 정해지지 않음 → 풀이 중단

## 조건별 역할
| 조건 | 하는 일(제거하는 자유도·케이스) | 빼면 생기는 일 |
|---|---|---|
| 최고차항의 계수 1, 삼차 | $f$의 꼴 고정 | 계수 배율이 자유 → 답이 정해지지 않음 |
| (가) | 이차식 $x^2-4x+c$의 중근 조건으로 $c=4$ 결정, $c=0$($t=0$ 포함) 제거 | $c$가 자유: $f(5)=5(5+c)$ 무수히 많음 (스크립트: 정수 $c$만으로 25개) |
| (나) | $f(0)=0$ → 원점을 단순근으로 숨김. 삼중근 $(x-\frac43)^3$·허근 섞인 꼴 제거 | $(x-\frac43)^3$, $(x-r)(\text{허근 이차식})$ 등이 (가)(다)를 만족 → 해 다수 (스크립트: 146개 값) |
| (다) | $x^2$의 계수 $=-4$ → 중근의 위치 $r=2$ 고정 | $x(x-r)^2$ ($r\neq0$)·$x^3$ 모두 가능 → 해 다수 |

## 검증
- 해의 유일성: (나)(다)로 $f=x(x^2-4x+c)$. $c=0$이면 $|A|=2$, $c\neq0$이면 $|A|$=($x^2-4x+c$의 실근 수)이고 판별식 $16-4c$의 부호로 $c<4$: 2, $c=4$: 1, $c>4$: 0 → $c=4$ 유일(기호 확인). 추가로 $c\in[-40,40]$ ($\frac14$ 간격) 전수와 정수 계수 $(b,c,d)\in[-8,8]^3$ 전수(4913개)에서 해는 $(b,c,d)=(-4,4,0)$ 하나.
- 극한 판정의 독립 확인: 풀이의 “단순근/중근” 규칙을 쓰지 않고 `sympy.limit`로 좌·우극한을 직접 계산해 $A$를 구한 값이 규칙과 35개 표본(정답, $x^2(x-4)$, $x^3$, $(x-\frac43)^3$, 무작위 중복근·허근 섞인 삼차식)에서 일치.
- 조건 필요성: (가)/(나)/(다)를 하나씩 빼면 $f(5)$ 후보가 각각 25개/146개/7개(정수 격자 탐색 범위 안)로 늘어남.
