- 대상: `items/q1~q15, q18, q19, q21~q30` (27문항). q16·q17·q20은 제작 중이라 이번 차수에서 제외(2차에서 검수).
- 기준: `design/blueprint.md` §1·§3·§4·§5.3·§6, `meta/rules`.
- 방법
  1. `pip install sympy` 후 `python3 items/verify/q<번호>.py` 전부 실행.
  2. **독립 재풀이**: 해설·스크립트를 보지 않고 문항 본문만으로 풀었다. 손풀이 외에 전수·수치 계산이 필요한 문항은 별도 코드로 다시 계산했다(`review/indep/`).
     - `review/indep/q14_q21.py`: q14 첫째항 1~4999 전수, q21 10장 배열 전수(4200가지).
     - `review/indep/q29.py`: 공 7개에 이름을 붙여 3회 시행 12³가지 경로 전수(분수 정확 계산).
     - `review/indep/q30_search.py`: (a, b) 격자 출발점에서 f(a)=g(a), f(b)=g(b) 수치 풀이 → 후보 2쌍, 이후 손풀이로 경우 분류.
  3. 문항 결함(유일성, 조건 누락·중복, 정의 모호, 표기, 그림-조건 일치, 정답 하나, 오답 선지, 단답 범위), 범위·기출 유사성, 시험 전체 분포를 점검했다.
